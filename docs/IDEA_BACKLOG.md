# Idea backlog

This is a parking lot, not an implementation queue. Ideas are captured so they are not lost, but only one gameplay initiative is active at a time.

## How to add an idea
Record:
- **Idea:** one sentence.
- **Player fantasy:** what the player gets to do or feel.
- **Why it matters:** which Signal pillar or core loop it strengthens.
- **Likely dependencies:** only if known.
- **Status:** parked / needs design / approved / active / shipped / rejected.

Do not implement a parked idea until it is selected as the next initiative and its player-facing rules are agreed.

## Approved direction
- **A personal starter hideout:** a modest, walkable house with functional furniture, storage and decoration. Status: active initiative.
- **A tactile workbench:** approach a physical bench, transition into a close-up visual workspace, manipulate represented objects, then return to the room. Status: active initiative.
- **A compact enterable city:** a small outdoor block with building entrances and simple interiors. Status: active initiative.
- **Parallel lifestyles:** legitimate and criminal play can be mixed freely; neither excludes the other. Status: approved direction.
- **Harsh criminal failure:** serious, potentially lasting consequences for criminal failure. Exact penalties and recovery rules need design. Status: approved direction.
- **Global crime progression:** all criminal activity contributes to one overall criminal level/progression track. Status: approved direction.
- **Crime as a core pillar:** fictional drug-related activity and a broad range of other illegal activities should be central game content. Specific activities and rules need design. Status: approved direction.
- **A satisfying legitimate livelihood:** farming, gathering, processing, crafting, services and trading should offer lower-risk progression. Example direction: grow wheat, process it into flour and bake bread; passive/delayed production should still require meaningful setup and collection. Status: approved direction.
- **A living, reactive city:** NPCs, clients, contacts, factions and world events create opportunities and consequences for both lifestyles. Status: approved direction.
- **Hideout as the emotional anchor:** home supports storage, preparation, recovery, workspaces, production and personalisation across both lifestyles. Status: approved direction.

## Candidate systems — needs design before implementation
- **Crime catalogue:** theft, burglary, fraud, counterfeiting, cybercrime, vandalism, fictional drug production/distribution and other suitable activities. Define activity loops, progression gates, rewards, failure states and content boundaries individually.
- **Global criminal progression:** define what actions grant progress, thresholds, unlocks and whether reputation is separate from level.
- **Harsh failure and recovery:** define the consequence tiers, what can be lost, temporary/permanent restrictions, and how players recover without making failure arbitrarily save-ruining.
- **Legal livelihood catalogue:** define crop/resource cycles, processing, selling, delayed production, costs and meaningful player involvement.
- **NPC/client system:** define identity, schedules, needs, requests, satisfaction, relationship changes and how contacts are discovered.
- **World events:** define event triggers, duration, locality, player agency and persistence.
- **Shared economy:** define currencies, prices, supply/demand and how legitimate and underground economies interact.
- **Reusable activity framework:** define activity definitions, objectives, interactions, outcome resolution, rewards/failures and save-state requirements. Candidate foundation for the next vertical slice.

## Parked ideas
Future ideas about specific money-making activities, loot rules, police response, NPC schedules, faction structures, and furniture placement rules should be captured here and agreed before implementation.
