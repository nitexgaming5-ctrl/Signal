# Idea backlog — parked concepts only

This file is a parking lot, not an implementation queue. Approved game direction is documented in Vision/Design; active priorities are in Roadmap. Do not duplicate approved decisions here.

## How to capture an idea

Record its player fantasy, why it strengthens a Signal pillar, likely dependencies, risks and status. Keep the note short. Ideas are not implementation commitments until selected into an active initiative and scoped as a player-facing slice.

## Parked livelihood concepts

- Material sourcing, sorting and processing where a concrete recipe needs it.
- Additional everyday production specialisations beyond the First Workshop.
- Repair/restoration services (future B-04).
- A limited set of authored customer requests and recurring clients (future B-05).
- A small NPC-owned production workspace using the same actor-aware production rules.

## Parked social / narrative concepts

- Deeper player-driven trust, affinity, favours and relationship consequences.
- Discoverable dual lives, secrets and local contact networks.
- Explicit witness reporting/sharing and scenario-specific rumours.
- Additional authored opportunities connected to existing NPC schedules and discoveries.

## Parked crime / pressure concepts

- Additional crime categories that build on physical interaction and ownership.
- Harsh but understandable failure/recovery tiers.
- Local exposure, evidence and witness consequences designed per crime scenario.
- Global criminal progression thresholds/unlocks, kept distinct from current heat.

## Parked world / economy concepts

- Additional connected neighbourhood blocks once the existing area is dense enough.
- Selective finite stock/restocking only for goods where scarcity is a real gameplay decision.
- Context-specific barter, specialist buyers and supplier relationships when a complete scenario needs them.
- Better content-authoring tools if ScriptableObject scale makes manual authoring costly.

## Parked references

- Schedule I, Drug Dealer Simulator, Probably Stolen, Torn Crimes, Stardew Valley, Stalker/Tarkov and Economy Engine were reviewed for experience and interaction inspiration. They are not templates or dependencies.
- No third-party runtime economy package or external gameplay code is approved.

## Guardrails

Do not build universal supply/demand, automatic NPC shopping, passive revenue, continuous economy simulation, a procedural contract marketplace, generic quest bloat or per-frame NPC AI as an answer to these ideas. Choose one small player-facing slice when the active initiative is complete.
