# Documentation archive

Historical research and superseded reference material lives here. It is retained for traceability and specialist investigation; it is not part of the normal agent reading path.

- `research/`: completed research/architecture proposals whose implementation has moved into current source-of-truth documents.
- `progress/`: dated handoff snapshots and append-only project history.
- `tasks/archive/`: completed or superseded task cards.

Current game scope and routing live in `docs/INDEX.md`; current status lives in `docs/PROGRESS.md`.
