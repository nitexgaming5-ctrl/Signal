# Survival item catalogue — Free Pixel Survival Items Pack

**Status:** First-pass authored catalogue; Unity import pending  
**Source:** User-supplied pack containing 100 separate 32×32 icons  
**Runtime source:** `Assets/_Project/Editor/SurvivalItemPackManifest.tsv`; generated definitions are placed under `Assets/_Project/Resources/SurvivalItems/Definitions/`.

Names and descriptions are visual interpretations because the pack numbers its icons without supplying individual item names. Grid sizes, stack limits and base values are provisional. Base values are inspection/reference values, not shop prices. All items start Standard quality, Good condition, Genuine authenticity and Legitimate ownership. No item effects, recipes, loot entries or shop stock are created by this catalogue alone.

## Import

Copy the `Icons` folder from the separate local import ZIP into `Assets/_Project/Resources/SurvivalItems/Icons/`, then run **Tools → Signal → Import Survival Items Pack** in Unity. The PNG files are excluded from the public repository by `.gitignore` because the pack licence prohibits uploading its graphics to public repositories. Keep the artwork local; the importer and this catalogue may remain version-controlled.
