# Task M1-01 — PlayerStats (logic only)

## Goal
Plain C# player stats with validation and change events. No UI, no scene, no save.

## Prerequisites
M0 complete. Answer Q1 in OPEN_QUESTIONS (recommended: Money and Health only).

## Specification
- `PlayerStats` class in `Signal.Core`
- `int Money` — never below 0
- `int Health` — 0 to 100, clamped
- `bool TrySpend(int amount)` — returns false and changes nothing if insufficient
- `void Earn(int amount)` — ignores zero/negative amounts
- `void Damage(int amount)` — ignores zero/negative amounts; clamps at 0
- `event Action<PlayerStats> Changed` — fires only when a value actually changes

## Tests (EditMode, Signal.Core.Tests)
- Starts at Money 0, Health 100 (or constructor arguments)
- Earn adds; negative and zero ignored
- TrySpend succeeds only with enough money; failure leaves money unchanged
- Damage clamps at 0; no event on zero damage
- Changed fires once per real change
